## 一、脚本（改 .ps1 后必跑）

### 1.1 语法检查（25 个）

```powershell
$bad = 0
Get-ChildItem '<包根>\src\app\Scripts' -Filter *.ps1 | ForEach-Object {
    $e = $null
    [System.Management.Automation.Language.Parser]::ParseFile($_.FullName, [ref]$null, [ref]$e) | Out-Null
    if ($e.Count) {
        Write-Host "❌ $($_.Name)" -ForegroundColor Red
        $e | Select-Object -First 2 | ForEach-Object { "     行 $($_.Extent.StartLineNumber): $($_.Message)" }
        $bad++
    }
}
Write-Host $(if ($bad -eq 0) { '✅ 25 个全部通过' } else { "❌ $bad 个失败" })
```

### 1.2 ⚠️ 脚本两处同步（最容易忘）

```powershell
$bad = 0
foreach ($f in Get-ChildItem '<包根>\dist\scripts' -Filter *.ps1) {
    $a = (Get-FileHash $f.FullName -Algorithm MD5).Hash
    $dst = "<包根>\src\app\Scripts\$($f.Name)"
    if (-not (Test-Path $dst)) { Write-Host "❌ 缺失 $($f.Name)"; $bad++; continue }
    $b = (Get-FileHash $dst -Algorithm MD5).Hash
    if ($a -ne $b) { Write-Host "❌ 不同步 $($f.Name)"; $bad++ }
}
Write-Host $(if ($bad -eq 0) { '✅ 两边一致' } else { "❌ $bad 个不同步（改的是 dist 还是 wpf？）" })
```

> 编译进 EXE 的是 `wpf\Scripts\`。改 `dist\scripts\` 之后必须同步，否则改动不生效。
