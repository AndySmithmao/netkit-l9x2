# 构建系统详解

## 依赖工具链

| 组件 | 版本 | 路径 | 必需？ |
|---|---|---|---|
| .NET SDK | 8.0.425+ | `C:\Program Files\dotnet` | ✅ |
| **VS BuildTools 2026** | 18.10.12336+ | `C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools` | ✅ **必须** |
| MicaSetup.Tools | 2.5.6 | `<MicaTools>\` | ✅ |
| 代码签名证书 | 自签名 | `<包根>\src\setup\cert\vrctool-codesign.pfx` | 可选 |

### 为什么必须是 VS 2026

MicaSetup 的安装器模板源码用了 **C# 14 的 `?.` 赋值语法**：

```csharp
// .dist\Design\Controls\ScrollViewer\SmoothScrollViewer.cs:428
_PART_VerticalScrollBar?.Value = _currentVisualOffsetVertical;
```

VS 2022 的 Roslyn（C# 13）编不了，报 `CS8652`。
MicaSetup.Tools **2.5.2 / 2.5.3 / 2.5.4 / 2.5.5 / 2.5.6 全都一样**。

### 获取 MicaSetup.Tools

```powershell
# 下载
$ver = '2.5.6'
& curl.exe -sL --max-time 120 -o "$env:TEMP\mica.nupkg" `
  "https://api.nuget.org/v3-flatcontainer/micasetup.tools/$ver/micasetup.tools.$ver.nupkg"

# 解压（nupkg 就是 zip）
Copy-Item "$env:TEMP\mica.nupkg" "$env:TEMP\mica.zip"
Expand-Archive "$env:TEMP\mica.zip" -DestinationPath '<MicaTools>\..\extract' -Force
```

## 构建流程（0 / 0.5 / 1~7，共 9 个阶段）

`build-installer.ps1` 的参数：

```powershell
param(
    [string]$Version       = '2.0.0',
    [string]$InstallFolder = 'VRChat优选工具',   # 决定 C:\Program Files\<这个>
    [string]$Publisher     = 'VRChat-Tool',
    # 下面两个留空就按「脚本所在位置」自动推导 —— 换台机器 / 换目录也能构建
    [string]$WpfDir        = '',   # 主程序目录（含 VrcTool.csproj）
    [string]$MicaTools     = '',   # 含 makemica.exe / bin\7z.exe / template\default.7z
    [switch]$SkipSign
)
```

> 2026-10-17 更新：`-WpfDir` / `-MicaTools` 是后加的。留空时 `$WpfDir = <脚本上一级>`、
> `$MicaTools = <WpfDir 的上级>\micasetup\extract\build`；交付包布局（`src\app` + `src\setup`）
> 建议显式传参，参见 `src\setup\_路径说明.txt`。

### 步骤详解

| 步 | 做什么 | 产物 | 耗时 |
|---|---|---|---|
| 0/7 | 检查 4 个工具（makemica / 7z / dotnet / MSBuild）+ 证书存在 | — | <1s |

| 3/7 | 7z 压缩 | `wpf\setup\VRChatTool.7z` 59.0 MB | ~40s |
| 4/7 | makemica 生成骨架 | `wpf\setup\.dist\` | ~35s |
| 5/7 | 改写 `.dist` 源码 | 程序集信息 + KeyName | <1s |

## 5/7 — 改写 `.dist` 源码

makemica 只改写 `Guid` / `AssemblyVersion` / `AssemblyFileVersion` / `RequestExecutionLevel` 和 `UseOptions` lambda，**不碰**这些：

```csharp
[assembly: AssemblyTitle("MicaApp Setup")]        // → VRChat优选工具 安装程序
[assembly: AssemblyProduct("MicaApp")]            // → VRChat优选工具
[assembly: AssemblyDescription("MicaApp Setup")]  // → VRChat优选工具 安装程序 - 免代理直连 VRChat
[assembly: AssemblyCompany("Lemutec")]            // → VRChat-Tool
[assembly: AssemblyCopyright("Under MIT License. Copyright (c) Lemutec Contributors.")]
option.KeyName  = "VRChatTool";                   // → VRChat优选工具（ASCII 校验绕过）
option.Publisher = "VRChat-Tool";
```

替换逻辑（**注意换行符归一化**）：

```powershell
$vm = Join-Path $DistDir 'Program.cs'
$vt = [IO.File]::ReadAllText($vm, [Text.Encoding]::UTF8).Replace("`r`n", "`n")

$pairs = @(
    @('[assembly: AssemblyProduct("MicaApp")]', "[assembly: AssemblyProduct(`"$AppName`")]"),
    @('option.KeyName = "VRChatTool";',         "option.KeyName = `"$InstallFolder`";"),
    # ...
)
foreach ($pr in $pairs) { $vt = $vt.Replace($pr[0], $pr[1]) }

[IO.File]::WriteAllText($vm, $vt.Replace("`n", "`r`n"), (New-Object Text.UTF8Encoding($true)))
```

**踩过的坑**：`KeyName` 传中文给 makemica 会被拒（`ERR: Invalid KeyName`），所以**传 ASCII 骗过校验，生成后再改回中文**。

## 5.5/7 — 注入环境检测

两件事：

### ① 复制 `EnvCheckHelper.cs`

```powershell
Copy-Item "$SetupDir\.inject\EnvCheckHelper.cs" "$DistDir\Helper\Setup\EnvCheckHelper.cs" -Force
```

`.dist\MicaSetup.csproj` 是 SDK 风格、默认通配 `**/*.cs`，所以放进去就自动参与编译。

### ② 给 `InstallViewModel.cs` 打补丁

**锚点**（在 `InstallHelper.CreateUninst(uninstStream);` 之后）：

```csharp
using Stream uninstStream = ResourceHelper.GetStream(".../Uninst.exe");
InstallHelper.CreateUninst(uninstStream);
```

**注入内容**：

```csharp
try
{
    ApplicationDispatcherHelper.BeginInvoke(() => {
        InstallProgress = 0;
        InstallInfo = "正在检测运行环境…";
    });

    string envReport = EnvCheckHelper.DescribeEnvironment();
    foreach (string line in envReport.Split(new[]{'\r','\n'}, StringSplitOptions.RemoveEmptyEntries))
        Logger.Information("[Env] " + line);

    string toolsDir = Path.Combine(Option.Current.InstallLocation, "tools");

    bool componentsOk = EnvCheckHelper.EnsureComponents(
        toolsDir,
        (progress, message) => {
            ApplicationDispatcherHelper.BeginInvoke(() => {
                InstallProgress = progress;
                InstallInfo = message;
            });
        },
        s => Logger.Information("[Env] " + s));

    if (!componentsOk)
        Logger.Warning("[Env] 加速组件下载失败…");
}
catch (Exception envEx) { Logger.Error(envEx); }
```

**可用的 API**（`MicaSetup` 提供的）：

| API | 说明 |
|---|---|
| `Logger.Information(params object[])` | 写日志（`Logger.Info` **不存在**） |
| `Logger.Warning` / `Error` / `Fatal` / `Exception` | 同上 |
| `ApplicationDispatcherHelper.BeginInvoke(Action)` | UI 线程调度 |
| `ApplicationDispatcherHelper.Invoke(Action)` | 同步版 |
| `RuntimeHelper.IsElevated` | 是否提权 |
| `Option.Current.InstallLocation` / `.ExeName` / `.AppName` | 配置 |
| `SimpleDownloadHelper.DownloadFile(url, file, cb)` | 简易下载（**没超时**，我没用它） |

## 6/7 — 编译顺序很关键

```
① MSBuild MicaSetup.Uninst.csproj   → bin\Release\MicaSetup.exe
② 签名它                            → 签名完整
③ 复制到 Resources\Setups\Uninst.exe  ← 塞回资源，这样卸载器也是签名的
④ MSBuild MicaSetup.csproj          → bin\Release\MicaSetup.exe（覆盖）
⑤ 签名它                            → 最终安装包
⑥ 复制出 wpf\setup\VRChat优选工具-安装包.exe
```

**顺序错了会怎样**：先编 Setup 再编 Uninst，最终安装包里嵌的是**没签名的** Uninst.exe。

**覆盖问题**：两个工程输出路径相同（都是 `bin\Release\MicaSetup.exe`），必须串行。

## 签名

```powershell
function Get-SignCert {
    if ($script:SignCert) { return $script:SignCert }
    $c = Get-ChildItem Cert:\CurrentUser\My -CodeSigningCert |
         Where-Object { $_.HasPrivateKey } | Select-Object -First 1
    if (-not $c) { throw '证书存储里没有可用的代码签名证书' }
    $script:SignCert = $c
    return $c
}

function Sign-File([string]$Path) {
    $cert = Get-SignCert
    $res = Set-AuthenticodeSignature -FilePath $Path -Certificate $cert `
             -HashAlgorithm SHA256 -TimestampServer 'http://timestamp.digicert.com' -EA SilentlyContinue
    if (-not $res -or $res.Status -notin @('Valid')) {
        # 时间戳不通就不打时间戳
        $res = Set-AuthenticodeSignature -FilePath $Path -Certificate $cert -HashAlgorithm SHA256
    }
}
```

⚠️ **`Get-PfxCertificate` 在 PS 5.1 没有 `-Password` 参数**，所以从**证书存储**取（`Cert:\CurrentUser\My`），不是从 `.pfx` 文件。

换证书：把新 `.pfx` 导入 CurrentUser\My 即可，代码不用改。

### 重新生成证书

```powershell
& '<包根>\src\setup\cert\make-cert.ps1'
```

生成自签名代码签名证书，导出 `.pfx`（密码 `vrctool`）+ `.cer`，并导入 Root / TrustedPublisher。

## 只编译主程序（改界面的快速循环）

```powershell
$env:PATH = "$env:ProgramFiles\dotnet;$env:PATH"
& "$env:ProgramFiles\dotnet\dotnet.exe" build '<包根>\src\app\VrcTool.csproj' -c Release -v minimal
```

产物：`wpf\bin\Release\net10.0-windows\`（9 个文件）

运行测试：把这个目录**整个**复制到一个干净位置（比如 `wpf\runX\`），提权启动即可。
**注意**：`ScriptHost` 会把脚本解压到 `%TEMP%\VrcTool\<随机>\`，所以不用手动准备 `scripts\` 目录。
